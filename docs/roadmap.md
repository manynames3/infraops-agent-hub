# Roadmap

## Phase 0: Scaffold

- Repository structure.
- Local Docker Compose.
- Mock n8n workflow.
- Prompt templates.
- Runbooks.
- Sample data.
- Audit schema.
- Safe scripts.

## Phase 1: Read-Only Context

- Hosted browser incident packet demo.
- Safe Pages Function mock API.
- Database portability docs for local Postgres development, optional Neon hosted demo persistence, and AWS-native production governance storage.
- AWS read-only context adapter.
- Log source adapter with redaction.
- Incident context pack builder.
- Unit tests for action classification.

## Phase 2: Human Approval Flow

- Approval request API.
- Slack draft approval message.
- Approval expiration.
- Approver identity capture.
- Audit event tests.

## Phase 3: LLM Integration

- LLM provider abstraction.
- Prompt versioning.
- Redaction pipeline.
- Safety evals for blocked actions.
- Cost and latency tracking.

## Phase 4: Controlled Automation

- Dry-run remediation adapters.
- Change windows.
- Policy-based allow lists.
- Rollback verification.
- End-to-end approval enforcement tests.

## Phase 5: Portfolio Demo

- Seeded demo incident.
- Screen-recordable hosted and local flow.
- Architecture diagram.
- Incident report export.
- Documentation polish.
